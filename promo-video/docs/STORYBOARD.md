# UFtouchHLE 宣传片：分镜与时间表（v1，与 src/config.ts 一致）

1920×1080 · 30 FPS · 总长 92 秒（2760 帧）· 简体中文

时间以秒计；「稳定」指文字完全显示且不在动画中的时长。转场 0.6–1.2 秒，统一使用 `Easing.bezier(0.45, 0, 0.2, 1)` 缓入缓出。

## 视觉规范

| 项 | 规范 |
| --- | --- |
| 背景 | 深藏青 `#0B1220` → 近黑 `#05070D` 的径向渐变，取自 Logo 底色；轻微暗角 |
| 强调色 | Logo 绿 `#8BD448`（极少量，仅用于细线与标签点） |
| 文字色 | 主文字 `#F2F4F8`，辅助文字 `#9AA4B8` |
| 中文字体 | 思源黑体 / Noto Sans SC（OFL），标题 Medium，正文 Regular，字距 0.04em |
| 英文字体 | Inter（OFL），游戏名与标签 |
| 字号 | 主标题 96px · 副标题 56px · 说明 44px · 辅助 34px |
| 运动 | 只用淡入、2–4% 缓慢推近（Ken Burns）、纵向 12–24px 位移；无旋转、无闪烁、无震屏 |
| 设备 | 早期 iPhone 与现代 Android 手机均以代码绘制的极简轮廓呈现，不使用 Apple 商标图像 |

## 声音

- 配乐：代码合成的原创 Cinematic Ambient，96 BPM（`scripts/make_music.py`）。
- 音效：转场处极轻的低频 swell，Logo 出现时一次柔和的钟音；不随鼓点切换画面。
- 游戏录屏原声默认静音，可在配置中按镜头开启低音量。
